🔍 Multi-Method Redirect Checker (Tanpa API JSON)

Masukkan URL awal, tool ini akan menggunakan 4 metode untuk mendapatkan URL akhir setelah redirect (termasuk jika berakhir dengan 403, 404, dll).

1️⃣ Direct (fetch)
Belum dicek
2️⃣ Proxy CORS (corsproxy.io)
Belum dicek
3️⃣ AllOrigins
Belum dicek
4️⃣ Redirect.li (HTML parse)
Belum dicek
⚠️ Metode Direct sering gagal karena CORS. Metode proxy (2 & 3) mengikuti redirect dan mengembalikan URL akhir.
✅ Metode 4 mengambil halaman redirect.li/http/?url=... dan mengekstrak URL akhir dari tampilan HTML (bukan API JSON), sehingga tetap bisa mendapatkan riwayat redirect meskipun API JSON bermasalah.
